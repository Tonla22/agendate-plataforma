Agendate

Agendate es una aplicación web de gestión de reservas para comercios de servicios.

Permite administrar reservas, agenda, profesionales, clientes y pagos desde un mismo panel, además de ofrecer una página pública para que los clientes puedan elegir un servicio, una fecha y un horario disponible.

Por qué Agendate solicita acceso a Google Calendar

La conexión con Google Calendar es opcional y solamente se activa cuando el propietario de un comercio decide vincular su cuenta desde el panel de Agendate. El acceso se utiliza para crear eventos de reservas confirmadas, actualizar esos eventos cuando cambia el turno y eliminarlos cuando la reserva se cancela.

Agendate también consulta el correo de la cuenta conectada para mostrar al comercio qué cuenta de Google está vinculada. Los datos de Google no se utilizan para publicidad ni se venden a terceros, y el comercio puede desconectar la integración cuando lo desee.
